AI Chess Web Application
A lightweight, browser-based chess engine developed during my sophomore year. This project features an integrated AI opponent with three difficulty levels, implemented entirely in client-side JavaScript.

Project Scope
The application provides a standalone chess-playing experience without the need for backend installation. The primary focus is the efficient implementation of search algorithms within a browser environment.

Key Features
Three AI Difficulty Tiers:

Easy: Moves based on basic evaluation, suitable for beginners.

Medium: Implements a Minimax search with a standard heuristic evaluation.

Hard: Utilizes Minimax with Alpha-Beta Pruning for optimized search depth and competitive play.

Standalone Architecture: A single HTML file manages all rendering, game logic, and AI computations.

Responsive Interface: Designed for accessibility across various screen sizes and modern web browsers.

Technical Implementation
Frontend: HTML5, CSS3, and Vanilla JavaScript.

Core Algorithms:

Minimax: Used for decision-making by simulating potential move sequences.

Alpha-Beta Pruning: Enhances search efficiency by pruning unnecessary branches in the search tree.

Heuristic Evaluation: A custom function that weights material value and strategic board positioning.

Setup
Download the index.html file.

Open the file in any modern web browser (Chrome, Firefox, or Edge).

Select a difficulty level to start the match.
